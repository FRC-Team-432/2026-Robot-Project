# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

FRC Team 432 (The Final Countdown) robot code for the 2026 FIRST Robotics Competition season. Built on Hemlock's Gray Matter Template (5712). Java 17, WPILib 2026, CTRE Phoenix 6 with swerve drive.

## Build Commands

```bash
./gradlew build          # Compile and run tests
./gradlew deploy         # Deploy to the RoboRIO
./gradlew simulateJava   # Run robot simulation with GUI
./gradlew test           # Run JUnit 5 tests only
```

## Architecture

### Command-Based Robot Pattern
The robot uses WPILib's command-based framework. Entry point is `Main.java` → `Robot.java` → `RobotContainer.java`.

- **`Robot.java`**: TimedRobot subclass. Configures Epilogue telemetry (HootAutoReplay + NetworkTables dual backend). Manages autonomous/teleop mode transitions via CommandScheduler.
- **`RobotContainer.java`**: Wires everything together — creates subsystems, configures controller bindings, builds auto routines. Uses `RobotBase.isSimulation()` to swap real/sim subsystem implementations.

### Subsystem Hierarchy
- **`CommandSwerveDrivetrain`** — Extends CTRE's `TunerSwerveDrivetrain` and implements WPILib `Subsystem`. Handles field-centric driving, odometry, vision measurement fusion, and alliance-aware operator perspective. Runs a separate sim thread at 5ms.
- **`Arm`** / **`ArmSIM`** — Single-jointed arm using TalonFX + CANcoder on the "canivore" CAN bus. Uses MotionMagic position control. SIM subclass adds physics simulation (SingleJointedArmSim) and Mechanism2d visualization.
- **`Flywheel`** / **`FlywheelSIM`** — Shooter flywheel using TalonFX with MotionMagic velocity control. SIM subclass adds DCMotor simulation.
- **`Superstructure`** — Coordinates Arm + Flywheel into high-level commands (stow, amp score, speaker close/far, intake ground). Provides both instant and "AndWait" variants of each command.
- **`LimelightSubsystem`** — AprilTag vision using Limelight camera with MegaTag. Feeds pose estimates into drivetrain's Kalman filter with distance-scaled standard deviations. Uses HootAutoReplay for replay support.

### Autonomous System
- **`AutoCommands`** — Reusable drive primitives: `driveTo`, `driveToWithAction`, `driveToThenExecute`, `distanceCommand` (trigger action at proximity).
- **`AutoRoutines`** — Composes AutoCommands + Superstructure into full autonomous sequences. Selected via SmartDashboard `SendableChooser`.
- **`LinearPathRequest`** — Custom `SwerveRequest` that uses CTRE's `LinearPath` for trapezoidal motion profiling with PID feedback + wheel force feedforward.
- **`Waypoints`** — Field positions as `Pose2d` constants (starting positions, intake spots, scoring positions, navigation waypoints).

### Constants Pattern
All tunable values live in `frc.robot.constants.*` classes. Each is a final utility class with `public static final` fields. Key files:
- `ArmConstants` — PID gains are currently zeros (needs hardware tuning)
- `FlywheelConstants` — Shooting speeds at 25/5/35 RPS for close/amp/far
- `AutoConstants` — Robot mass, motion constraints, path-following PID
- `VisionConstants` — Standard deviation base values and ambiguity threshold

### Generated Code
- **`TunerConstants`** (in `generated/`) — Swerve module configuration generated by CTRE Tuner X. Contains CAN IDs, encoder offsets, gear ratios, PID gains. **Do not hand-edit** — regenerate via Tuner X.
- **`build/generated/`** — Epilogue annotation processor output (`*Logger.java`). Auto-generated, not checked in.

### Key Patterns
- **Sim/Real Branching**: `RobotBase.isSimulation()` ternary in RobotContainer picks between real hardware classes and `*SIM` subclasses.
- **Epilogue `@Logged`**: Annotation on Robot, RobotContainer, and subsystems auto-generates telemetry logging code.
- **TalonFXUtil**: Config retry helper — always use `TalonFXUtil.applyConfigWithRetries()` when applying motor configs.
- **Command Naming**: All commands returned from subsystems use `.withName()` for dashboard identification.

### Vendor Dependencies
- **CTRE Phoenix 6** (with replay support) — Swerve drive, TalonFX motors, CANcoders, Pigeon2 IMU
- **WPILib New Commands** — Command-based framework

### CAN Bus Layout
- Default CAN bus (`""`): Swerve modules (drive/steer TalonFX, CANcoders), Pigeon2 (ID 30), Flywheel (ID 35)
- `"canivore"` bus: Arm TalonFX (ID 31), Arm CANcoder (ID 32)
